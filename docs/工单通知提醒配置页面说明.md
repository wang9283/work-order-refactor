# 工单通知提醒配置页面说明

> 用途：面向管理端提供统一的“工单通知提醒配置”入口。
> 当前为原型 Demo，已完成配置 CRUD，并联动站内消息模拟发送。

## 入口

PC 管理端 → 左侧菜单「集成与审计」→「工单通知配置」

## 页面能力

| 能力 | 说明 |
|---|---|
| 新建通知规则 | 选择工单类型、触发事件、通知对象、通知渠道、内容模板 |
| 编辑/停用/启用/删除 | 支持对已有规则进行维护 |
| 集团标准 + 子公司作用域 | 集团可配置标准规则；子公司可查看集团标准规则（只读）并维护本组织规则 |
| 触发事件 | 创建、变更、完成、超期、临期、已关闭、已取消 |
| 超期/临期条件 | 超期：大于等于 N 天；临期：小于等于 N 天（按天配置） |
| 通知对象 | 执行人、创建人/发起人、指定角色、指定人员 |
| 通知渠道 | 站内消息、App 推送、短信 |
| 内容模板 | 支持占位符：`{typeName}`、`{ticketNo}`、`{event}` |

## 数据模型

```js
{
  id: 'nr_1',
  name: '生产任务-创建通知',
  scope: 'group', // group=集团标准，subsidiary_id=子公司私有
  ticketTypeId: 't_prod',
  event: 'created', // created/updated/completed/overdue/nearDeadline/closed/cancelled
  enabled: true,
  targets: ['executor', 'creator', 'role', 'person'],
  roles: ['subsidiary_manager'],
  personIds: ['p1'],
  channels: ['site', 'app', 'sms'],
  reminderOperator: 'gte', // 超期/临期时使用：gte=大于等于，lte=小于等于
  reminderDays: 3,
  template: '您有一条新的「{typeName}」工单 {ticketNo} 待处理',
  createdAt: '',
  updatedAt: ''
}
```

## Demo 联动

- 创建工单时，按 `created` 规则生成站内消息。
- 提交完工 / 强制完结时，按对应事件规则生成站内消息。
- 超期 / 临期当前为配置展示，后续由定时任务按“截止时间 + 天数条件”扫描触发。
- App 推送和短信当前为配置展示，后续接入真实服务商。
