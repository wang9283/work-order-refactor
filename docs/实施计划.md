# 工单重构原型 · 实施计划

> 原则：按模块分批验证，PC 与 App 同源共享配置。当前目录 `work-order-refactor` 为独立原型。

## 批次总览

| 批次 | 模块 | 验收重点 |
|---|---|---|
| B0 | 项目骨架 + 共享数据层 | PC/App 同源运行，共享 localStorage |
| B1 | 任务大类 + 工单模板构建 + 工单类型配置 | 三大基础配置可跑通 |
| B2 | 基础主数据 | 组织/人员/班次/字典/生产线/物料可维护 |
| B3 | 排班与执行人范围 | 月排班、日排班、改派可演示 |
| B4 | 工单执行流程 | App 填写、提交完工、待数据、超时完成 |
| B5 | 报表与薪酬 | 工单汇总、任务完成情况、贡献调节、收入核对 |
| B6 | 集成与预留 | 外部系统/API Key、操作日志、站内消息、灰色预留入口 |

---

## B0 项目骨架 + 共享数据层

### 目标
- 新目录独立运行。
- PC（React + Ant Design）与 App（React + antd-mobile）同源共享 localStorage。
- 公司 logo 展示。

### 产出
- `package.json`、`vite.config.js`
- `index.html`（PC）、`app.html`（App）
- `src/shared/`：constants、demoData、store
- `src/admin/`、`src/mobile/` 骨架

### 验收
- 两端可启动。
- PC 切换组织后，App 可读取当前组织配置。

---

## B1 任务大类 + 工单模板构建 + 工单类型配置

### 任务大类
- 页面：任务大类列表。
- 支持新增、停用、排序。
- 编码全局唯一，发布后锁定。
- 权限：集团管理员维护集团标准；子公司配置管理员维护本组织大类。

### 工单模板构建
- 页面：表单列表、表单设计器。
- 主表单字段 / 子表单 / 子表单字段弹窗编辑。
- 版本：草稿 / 发布；编辑已发布表单生成新草稿版本。
- 条件逻辑入口灰色预留。

### 工单类型配置
- 页面：类型列表、类型编辑。
- 基础信息、编码、任务大类、表单绑定、触发规则、时限窗口、通知配置。
- 集团标准类型 + 子公司运营覆盖。
- 手动触发默认一条可停用不可删除；API 触发仅集团标准类型可配。
- 子公司自有类型不支持 API 触发。

### 验收
- 能创建任务大类、表单并发布。
- 能创建工单类型并绑定已发布表单。
- 集团标准类型可在子公司视角覆盖触发/时限/通知。

## B2 基础主数据

### 行政组织管理
- 集团 / 片区 / 子公司三级。
- 组织编码全局唯一，发布后锁定。
- 新增、停用；删除按钮保留。

### 人员档案
- HR 核心信息只读展示。
- 本系统维护：资质标签、执行人范围、排班/请假状态。
- Demo 用模拟 HR 数据 + 同步HR入口。

### 班次管理
- 子公司各自维护。
- 字段：名称、开始时间、结束时间、跨天、状态、排序。
- 被排班引用不可停用。

### 数据字典
- 集团标准 + 子公司扩展。
- Demo 先做：任务大类、洗消类型、生产线、物料单位。

### 生产线 / 物料档案
- 子公司各自维护。
- 被引用不可停用。

### 设备档案
- 灰色预留入口。

### 验收
- 基础数据可维护，且工单类型/模板/排班可引用。

---

## B3 排班与执行人范围

### 执行人范围
- 工单类型上配置：默认执行人（一人或多人）、其他执行人。
- 集团标准类型的执行人范围由各子公司独立设置。

### PC 月排班
- 粒度：人 + 日期 + 班次。
- 状态：出勤 / 请假 / 休息。

### App 日排班
- 仅子公司管理使用。
- 人员出勤状态展示。
- 待处理列表：当前员工可执行的所有未开始任务（含未指派和已指派但未开始）。
- 改派人员选择可搜索：默认其他执行人，可切全部人员。

### 验收
- 月排班可维护。
- 日排班可改派。
- 默认执行人请假时，工单可进入日排班待处理。

## B4 工单执行流程

### App 任务列表
- 状态 Tab：全部 / 待开始 / 执行中 / 待数据 / 已超时 / 已完成。
- 快速新建：输入编码创建任务并生成工单编号。

### App 任务详情
- 按表单版本渲染主表单 + 子表单。
- 字段渲染：文本、数字、单选/多选、附件/拍照/签名按钮、点击确认、日期时间。
- 提交完工：阻塞字段校验，允许后补字段进入待数据。
- 超时完成：输入理由，进入已完成并标记超时完成。

### 子公司管理操作
- 超时完成 / 强制完结 / 复核。
- 待数据查看数据到位情况。

### 外部数据 mock 回写
- Demo 可模拟外部系统回写，数据到位后自动完成。

### 验收
- 从快速新建到提交完工全流程可跑通。
- 阻塞/后补字段行为符合方案。

## B5 报表与薪酬

### 报表中心
- 工单汇总、任务完成情况。
- 维度：组织、任务大类、工单类型、时间范围。
- 表格 + 统计卡。

### 贡献调节
- 工单完成后，子公司负责人调节参与人比例。
- 默认平均，总和校验 100%。
- 双端支持批量调整、增加/删除人员。

### 收入核对
- 子公司负责人核对，集团管理员只读。
- 双端展示，不实际计算金额。

### 单价 / 计件标准
- 集团统一维护。
- Demo 只做配置展示。

### 验收
- 报表可查看。
- 贡献比例可调节并保存。
- 收入核对可展示。

## B6 集成与预留

### 外部系统 / API Key
- 外部系统注册：集团级 / 子公司级。
- API Key 统一由集团管理，类型区分触发 / 回写。
- Demo 模拟生成、吊销、复制。

### 操作日志
- PC 端日志页，支持筛选。
- 记录关键操作。

### 站内消息中心
- PC 铃铛 + 列表页；App 消息入口。
- 工单生成通知、系统通知实际产生站内消息。

### 预留入口
- 设备档案、角色管理、账号管理、数据权限规则、条件逻辑、导出等：灰色显示。

### 验收
- 集成配置可演示。
- 日志可追溯。
- 消息可查看。
- 预留入口灰色可见。
