# 演示身份与生产基地上下文由服务端会话管辖

PC 和 App 不再要求用户填写账号密码。每端从服务端返回的白名单中选择演示身份，页面直接进入该身份对应的既有账号、人员关系和能力授权。正式账号密码认证接口保留兼容，但页面不展示登录表单。

演示身份只传递白名单标识，服务端负责映射账号并签发会话。客户端不能提交自定义角色、能力、人员或数据范围。生产经理、班组长、员工和洗消工即使底层共用执行人角色，也映射到不同人员账号，以便真实体现本人数据、班组管理范围及现场作业关系。

生产基地选择保存在服务端会话中，并作为所有业务读取与写入的当前范围。可选基地取当前身份已有能力与数据授权覆盖的启用基地交集；切换基地只能收窄范围，不能制造权限。“全部基地”不设默认汇总模式，跨基地标准、组织和作业字典仍按共享资源规则处理。

PC 和 App 使用不同的令牌、身份和基地存储键。两端可以同时展示不同视角，刷新后分别恢复最近一次有效选择，业务数据仍共用。切换前等待进行中的写请求并确认未保存修改；切换成功后按上下文版本卸载旧页面和旧响应，失权页面转到首个可访问页面。

该决定补充 ADR 0001 的双端职责，不改变组织、工单、排班、工作量或薪资领域规则。
