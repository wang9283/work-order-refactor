# PC 排班采用班组整月表，App 承接当天调整

PC 排班计划以「作业组 × 排班归属日」整月表为主视图，固定呈现当前可管理的作业组，并显示班次、安排人数、日调整、跨天归属及洗消工单摘要。普通料生产班、预混料生产班、装卸班和洗消班是本期示例中的四个作业组；洗消班虽为单人作业组，仍按作业组排班并关联工单类型。班次维护留在基础资料，工单类型默认派单留在其他工单配置，排班页只提供只读摘要与跳转。

PC 负责未来及当天的月度默认安排，App 负责当天换人、加人和岗位调整；PC 对历史日期和 App 产生的当天调整只读，不把日调整改写回月排班。批量保存覆盖已有安排前展示日期、班组、班次及人员差异，并使用排班 `revision` 拒绝并发覆盖。空白日期表示未安排，不推断休息或缺岗。该决定保留 ADR 0001 和 0004 的月／日共读、默认派单及历史快照边界。
