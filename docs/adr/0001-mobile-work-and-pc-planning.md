# App 承接日常作业，PC 承接月度安排

产品聚焦饲料总部及各基地的生产、装卸作业与计件工作量管理，通用工单作为补充。PC 以生产经理的月排班和人员分配调整为主要操作，开单作为低频能力保留；App 承接员工日常作业和工作量确认，以及小组长或生产经理的日排班、本组人员分配调整。后续页面和流程按上述职责组织，以匹配各角色的实际工作方式和操作频率。

月排班提供月度默认安排，日排班在同一套安排上处理当天换人、加人、岗位调整等例外，没有调整时沿用月度安排。生产、装卸工单以业务系统生成和状态同步为主，员工自主开单、完单主要用于临时工作或其他工单。人员分配调整主要改变分配到人的工作量或贡献比例，保持整单工作量不变。
