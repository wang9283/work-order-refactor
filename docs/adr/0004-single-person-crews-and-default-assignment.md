# 单人作业组通过排班确定默认执行人

洗消、仓管等现场作业可以由仅有一名实际成员的洗消班、仓储班承接；作业组用于关联适用工单类型、排班和管理范围，不要求为使用分配功能而虚构多人。其他工单生成时，按工单类型、作业组和当天排班确定默认执行人，例如洗消工 A 当天值班，洗消工单默认由 A 承接。单人作业默认分配 100%，不展示无意义的比例调整；临时多人协作时再记录实际参与人员并调整贡献比例。班次由基地自行维护，初始示例为白班 08:00–20:00、夜班 20:00–次日 08:00、常日班 08:00–17:00，不把示例时间固化为统一制度。

允许人员在不改变原作业组归属的情况下，临时加入另一作业组的当天安排；之后生成的工单可按替班安排确定执行人，既有工单保留原人员记录。跨天班次按结束日确定排班归属日，并在页面注明实际开工时间。基地可维护班次名称、开始时间和结束时间，结束时间早于或等于开始时间表示跨天；既有排班及工单保留当时的时间快照。本期不实现轮班周期、打卡考勤或工时核算。
