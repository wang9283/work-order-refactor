# 按作业域划分工单写入边界

生产、装卸、洗消和其他工单共用同一工单底座，但不共用同一套人工执行流程。

生产、装卸只接收外部业务系统的工单、业务字段、数量和状态结果。平台不提供人工新建、开始、结束、提交或审核入口，也不允许修改业务字段、整单工作量和状态；授权人员只能调整参与人员和贡献比例，员工继续确认或反馈本人工作量。平台的人员调整不改写上游业务结果。

生产保持一张主单、多条岗位明细。本期 demo 只给不同岗位补充少量独立示例字段，在现有详情中灰色只读展示；不新增字段配置系统，不改造权限、接口或执行模型，也不拆单。

洗消是已启用的独立现场作业域，不是普通其他工单。车辆洗消和厂区洗消保留各自专用执行过程、凭证规则和员工自主完单；继续复用默认作业组、排班人员快照、分配、确认、反馈和输出能力。本期继续固定车辆 7 个点位和厂区 3 个区域，不开放通用流程设计器。

其他工单继续使用通用表单和自主完单能力。上述生产、装卸业务边界不削弱洗消和其他工单的现有流程，本期也不据此扩张权限或服务端接口改造。
