## 四、共享数据层

- `src/shared/constants.js`：状态/触发/字段/通知等共享常量。
- `src/shared/demoData.js`：组织、人员、表单、类型、工单、排班、消息等演示数据。
- `src/shared/store.js`：localStorage 存取、组织覆盖、编码生成、工单编号生成。

PC 与 App 同源运行，共用 localStorage，保证 PC 新增类型后 App 直接可见。

## 五、关键业务规则

- 表单与工单类型一对一。
- 集团标准 + 子公司覆盖运营配置；表单结构只读。
- 编码全局唯一，发布后锁定。
- 工单编号：`类型编码-组织编码-YYYYMMDD-4位流水号`。
- 字段策略：阻塞完成 / 允许后补 / 不阻塞。
- 状态模型：待分配 / 待开始 / 执行中 / 待数据 / 已超时 / 已完成 / 已关闭 / 已取消。
- 已超时处理：超时完成、强制完结、复核。

## 六、已知限制

- 排班、外部数据回写、通知触达均为模拟。
- 删除逻辑大部分仅保留入口，未实现。
- 条件逻辑、角色/账号/数据权限/设备档案为预留。
- 金额不实际计算。
- antd 整包引入导致 PC 端 chunk 较大，Demo 不影响使用。
