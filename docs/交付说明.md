## 四、共享数据层

- `src/shared/constants.js`：状态/触发/字段/通知等共享常量。
- `src/shared/demoData.js`：组织、人员、表单、类型、工单、排班、消息等演示数据。
- `src/shared/store.js`：localStorage 存取、组织覆盖、编码生成、工单编号生成。

PC 与 App 同源运行，共用 localStorage，保证 PC 新增类型后 App 直接可见。

## 五、关键业务规则

- 表单与工单类型一对一。
- 集团标准 + 子公司覆盖运营配置；表单结构只读。
- 编码全局唯一，发布后锁定。
- 工单编号：`类型编码-组织编码-YYYYMMDD-4位流水号`。
- 字段策略：阻塞完成 / 允许后补 / 不阻塞。
- 状态模型：待分配 / 待开始 / 执行中 / 待数据 / 已超时 / 已完成 / 已关闭 / 已取消。
- 已超时处理：超时完成、强制完结、复核。

## 八、v2.1 轻量化批次（2026-09-30）

原则：系统做轻、减少操作、只露核心字段、先用高频操作培养习惯，高级能力后置加码。

### App 执行端
- TabBar 5 → 3：首页 / 任务 / 我的；日排班、贡献、收入收进「我的」（管理角色低频功能）。
- 状态 Tab 收敛为「全部 / 待办 / 进行中 / 已结束」；「待数据」「已超时」仅在组织内存在此类工单时动态出现。
- 任务卡片只露：类型、编号、截止时间、状态。
- 任务详情首屏只渲染必填字段，选填收进「更多信息」折叠；「超时完成」按钮仅在已超时状态出现。
- 提交完工校验 = 必填（required）∪ 阻塞（blocking）：两者是不同口径——必填是表单级"必须填"，阻塞是字段级"数据必须已到位"，任一为空均不能提交；去掉后补确认弹窗，「允许后补 → 待数据」暂不触发，待外部回写接入后恢复两阶段。拍照/附件点击写入「已上传（原型）」占位值，避免 required 拍照字段无值可填。

### PC 管理端
- 工单类型列表收敛为 6 列：名称（含来源 Tag）、编码、任务大类、表单、状态、操作。
- 工单类型编辑抽屉首屏五项：名称、编码、任务大类、表单绑定、触发方式；所属组织 / 类型来源 / 备注、时限窗口、执行人范围、生成通知收进「高级设置」折叠。
- 通知配置开放事件「创建 / 完成」、渠道「站内消息」；历史规则的其他取值仍可查看与编辑。
- 报表中心只保留「任务完成情况」统计卡 + 明细表；工单汇总与多维分析后置。
- 左侧菜单高频前置、低频收二级：默认展开「工单类型配置」「排班与执行」，「排班与执行」内工单管理在前；「贡献调节 / 收入核对 / 单价计件标准」收进「薪酬核算（低频）」子菜单，「外部系统 / API Key」收进「外部集成（低频）」子菜单。

### 不减的内部骨架
8 态状态机、工单编号规则、编码发布锁定、表单版本锁定、集团标准 + 子公司覆盖规则。

## 九、角色视角权限（2026-09-30）

原则：每个角色打开只见自己该见的，入口过滤 + 关键动作拦截双保险；演示用轻量权限，不建账号体系。

### 角色（来自《迭代方案》§七）
集团管理员 / 子公司配置管理员 / 子公司工单管理员 / 子公司负责人 / 执行人。集团组织只有集团管理员；子公司组织可切四种角色。组织与角色选择器在 PC 顶栏，App 端在「我的 → 切换角色视角」，双端共用 localStorage、切换即时同步。

### PC 端菜单可见性（src/shared/roles.js）
- 首页：人人可见；执行人 PC 端仅首页。
- 工单类型配置（类型/大类/模板）：集团管理员 + 配置管理员。
- 排班与执行（工单管理/月排班）：集团管理员 + 工单管理员。
- 薪酬与报表：报表中心给管理角色；薪酬核算子菜单（贡献/收入/单价）只给负责人 + 集团管理员。
- 集成与审计：通知配置、外部集成=配置类；日志=配置+工单管理员；站内消息人人可见。
- 基础主数据：集团 + 配置管理员 + 工单管理员。
- 切换角色后若当前页面无权访问自动回首页；组织切换同步重校验角色。

### 关键动作拦截
- PC 工单管理：超时完成 / 强制完结 / 复核 / 模拟数据到达 → 工单管理员 + 集团管理员，其他人只见「—」。
- PC 贡献调节：仅子公司负责人，其他人只读。
- App 任务页：快速新建 / 可执行类型列表 / 提交完工 / 超时完成 / 添加子表记录 → 仅执行人；其他角色任务列表只读并提示「当前为只读视角」。
- App「我的」：日排班=工单管理员，贡献/收入=负责人；无匹配角色显示「当前角色无管理功能」。

### 实现位置
`src/shared/roles.js`（角色/菜单/能力定义）、`store.js`（currentRole 存取）、`admin/App.jsx`（选择器+菜单过滤）、双端各页面动作显隐。
