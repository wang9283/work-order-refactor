# 工单类型配置 & 工单模板构建 · 重构迭代方案

> 状态：方案讨论已收敛，原型按本方案推进
> 基线：现有 `Prototype/` 不动，本目录为独立重构原型

## 一、核心决策

1. 表单与工单类型一对一。
2. 子表单不跨表单复用。
3. 定时触发统一到「工单类型配置」模块。
4. 集团标准 + 子公司可覆盖运营配置；表单结构只读，由集团统一升级。
5. 组织层级：集团 / 片区 / 子公司；片区仅结构层，不直接管理配置。
6. 子公司可创建自有类型/表单，但不支持 API Key 触发。
7. 任务新建时可输入编码快速创建任务。
8. 编码全局唯一，系统自动生成可手改，发布后锁定。
9. 覆盖规则：未覆盖自动继承，已覆盖保持，可恢复继承。
10. 表单更新下次发布/下次生成生效，历史工单锁定创建时版本。

## 二、状态模型

| 状态 | 性质 |
|---|---|
| 待分配 | 过程态 |
| 待开始 | 过程态 |
| 执行中 | 过程态 |
| 待数据 | 过程态：执行人已提交完工，等待外部数据 |
| 已超时 | 异常中间态 |
| 已完成 | 正常终态 |
| 已关闭 | 异常终态 |
| 已取消 | 异常终态 |

流转：

```
待分配 → 待开始 → 执行中 → 待数据 → 已完成
                     ↘
                     已超时 → 超时完成 → 已完成
                            → 强制完结 → 已关闭
                            → 复核 → 保留已超时
```

## 三、两阶段完成与字段策略

1. 执行人填写完成，点击「提交完工」。
2. 系统检查外部数据字段：
   - 无需等待的数据已到齐 → 已完成。
   - 需要等待的数据未到齐 → 待数据。
3. 外部系统自动回传，数据到齐后系统自动完成。

| 字段策略 | 执行人提交完工 | 工单最终完成 |
|---|---|---|
| 阻塞完成 | 字段必须已有值，否则不能提交完工 | 提交后直接完成 |
| 允许后补 | 字段可为空，先提交完工 | 数据到齐后自动完成 |
| 不阻塞 | 不影响提交 | 不影响完成 |

## 四、时限窗口

同一配置框：开始时间 + 结束时间 + 允许提前开始 + 允许延后结束。

## 五、已超时处理

| 操作 | 结果 |
|---|---|
| 超时完成 | 执行人或管理员操作，输入理由必填，进入已完成，算正常完成但标记「超时完成」 |
| 延期 | 保留，Demo 暂不实现 |
| 强制完结 | 管理员操作，进入已关闭 |
| 复核 | 必填结论和原因，保留已超时 |

## 六、外部系统与 API Key

- 外部系统注册：集团级 / 子公司级。
- 集团级外部系统可服务全部或指定子公司；子公司级仅本组织。
- API Key 统一由集团管理，Key 增加类型区分：触发 / 回写。
- 字段外部数据来源引用外部系统 ID。

|---|---|---|

| 子公司配置管理员 | 子公司 | 自有类型/表单、覆盖运营配置 |

执行资质矩阵：后续单独聊，Demo 预留。

## 八、任务大类

- 工单类型所属分类命名为「任务大类」。
- 任务大类走字典。
- 集团统一维护标准任务大类，子公司可扩展本组织任务大类。
- 集团标准类型必须选集团标准任务大类；子公司自有类型可选集团标准或本组织任务大类。
- 任务大类编码全局唯一，系统生成可手改，发布后锁定。
- 任务大类需要独立维护入口：Demo 阶段增加「任务大类」页面，支持新增/停用/排序。
- 集团管理员维护集团标准任务大类；子公司配置管理员可新增本组织任务大类。


## 八补、工单编号规则

- 格式：`工单类型编码 + 行政组织编号 + YYYYMMDD + 4位流水号`
- 使用 `-` 分隔。
- 示例：`PROD-QD-20260814-0001`
- Demo 阶段行政组织编号用字母：集团 `JT`、华东片区 `HD`、青岛 `QD`、德州 `DZ`。
- 流水号按“类型 + 组织 + 日期”维度递增，每日从 0001 开始。
- 快速新建任务时，系统同时生成工单编号。

## 八补2、编码规则

- 编码只允许大写字母和数字，字母开头。
- 任务大类编码：2~4 位大写字母，如 `PROD`。
- 工单类型编码：2~8 位大写字母/数字，如 `PROD`、`VWASH`、`QD001`。

## 八补3、任务大类生命周期

- 一个任务大类下可有多个工单类型。
- 一个工单类型必须属于一个任务大类。
- 任务大类下仍有已发布工单类型时，不允许停用。

## 八补4、通知配置

- Demo 阶段只做配置展示，不实际发送。
- 指定人员可从人员数据中选择，但不实际触达。
- 人员选择按当前组织范围过滤。

## 八补5、触发规则

- 手动触发：每个工单类型默认一条，可停用不可删除。
- 开放 API 触发：仅集团标准类型可配置，子公司自有类型不显示该选项。
- 单次定时：Demo 阶段只保存配置，不实际生成。

- 通知渠道默认值：站内消息 + App推送。


- 已停用任务大类，新建类型时不可选；历史工单不受影响。
- 删除：Demo 阶段删除按钮保留，删除逻辑可不实现。


- 编码全局唯一，系统自动生成可手改，发布后锁定。
